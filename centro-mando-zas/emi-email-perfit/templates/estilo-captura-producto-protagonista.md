# Template - Estilo captura / producto protagonista premium

## Objetivo

Usar este estilo cuando Mica pida que el email se parezca a la captura del mail de Simona: una pieza visual, editorial-comercial, con un producto protagonista, texto de valor y CTA de venta.

Este estilo NO es una promo-grilla. No debe parecerse al archivo de cierre con hero marron, alerta de promo y cuatro productos. Debe parecerse a la captura: mas premium, mas editorial, mas estetico, con un producto central y beneficios explicados.

## Cuándo usarlo

Usar este estilo cuando Mica diga o sugiera:

- como la captura
- como el mail del jean
- producto protagonista
- venta + valor
- quiero algo mas visual
- estilo Simona premium
- que estiliza / resuelve el look / por que funciona
- email con argumento del producto
- no como el archivo de promo grilla

## Estructura obligatoria

1. Preheader oculto.
2. Contenedor central de 600 a 620px.
3. Header con logo simple de la marca.
4. Hero visual grande:
   - imagen o bloque visual protagonista.
   - texto grande superpuesto o integrado, con tipografia fuerte.
   - frase tipo editorial/comercial.
5. Bloque de introduccion:
   - pill o etiqueta: VENTA + VALOR, PRODUCTO PROTAGONISTA, NUEVO FAVORITO, etc.
   - titulo fuerte.
   - bajada corta que explique por que importa.
6. Card de producto protagonista:
   - imagen del producto.
   - nombre del producto.
   - descripcion breve.
   - precio de lista si esta validado.
   - precio con promo si esta validado.
   - cupón o beneficio si esta validado.
   - cuotas si estan validadas.
   - CTA Ver producto.
7. Seccion de argumento:
   - titulo: Por que funciona tan bien / Por que lo vas a usar tanto / Que lo hace diferente.
   - 3 beneficios numerados en cards verticales.
8. Cierre emocional-comercial:
   - bloque de color solido oscuro o de marca.
   - frase fuerte.
   - breve refuerzo.
9. CTA final ancho.
10. Condiciones legales / aclaraciones si hay promo.
11. Redes.
12. Footer con `${urls.unsubscribe}`.

## Estilo visual

- Visual premium, ordenado y aspiracional.
- Mucho aire y jerarquia.
- Paleta tomada de la marca o del producto.
- Tipografia fuerte en hero.
- Cards con bordes suaves.
- Bloques de beneficios numerados.
- CTA oscuro o de marca.
- Mobile first y responsive.

## Estilo de copy

- Voseo argentino.
- Cercano, canchero, claro y comercial.
- No escribir como blog largo.
- No escribir como promo agresiva.
- Combinar venta + valor: explicar por que el producto sirve, se usa y conviene.
- La venta aparece desde el producto protagonista, pero el argumento sostiene el deseo.

## Reglas criticas

- No convertir este estilo en grilla de muchos productos.
- No usar 4, 6 u 8 productos salvo pedido explicito.
- No usar alerta amarilla de promo ni estructura de cierre de promo si Mica pidio captura.
- No hacer un hero generico sin imagen cuando hay producto protagonista.
- No dejar placeholders finales.
- Si falta imagen publica, entregar prompt de imagen y una alternativa visual sin imagen.
- Si falta precio o promo, marcarlo como dato a validar y no inventarlo.

## Checklist antes de entregar

- Se parece a la captura y no al archivo de promo-grilla.
- Tiene producto protagonista.
- Tiene bloque de valor con 3 beneficios.
- Tiene CTA de producto y CTA final.
- Tiene footer con desuscripcion Perfit.
- Tiene resumen visible para Mica.
- Tiene HTML responsive listo para Perfit.
