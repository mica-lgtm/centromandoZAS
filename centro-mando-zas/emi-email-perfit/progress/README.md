```md

## Contexto leído

## Decisiones tomadas

## Supuestos usados

## Links usados

## Datos pendientes de validar

## Estado actual

## Próximo paso
```

Emi debe escribir acá cuando una campaña quede a medio camino, cuando haya varias piezas o cuando la tarea deba retomarse más adelante.
