Read the `README.md` file within this skill, and explore the other available files (`colors_and_type.css`, `fonts/`, `assets/`, `preview/`, `ui_kits/social/`).

If creating visual artifacts (social posts, stories, carousels, ads, email banners, WhatsApp pieces, mocks, throwaway prototypes), copy assets out and create static HTML files for the user to view — start from `ui_kits/social/` components and always link `colors_and_type.css`. If working on production code, copy assets and read the rules here to become an expert in designing with this brand.

Core rules to never break: one color recipe per piece; red `#B32626` only for the commercial signal (CTA/price/discount), yellow `#FFCC00` only for high-impact statements; warm neutral base everywhere else; Elms Sans ExtraBold/Black tight titles; real warm-light photography as the hero; short statement copy in Spanish; generous margins; no emoji, no gradients, no clutter.

If the user invokes this skill without any other guidance, ask them what they want to build or design (which channel, commercial vs. value content, which products/categories), ask a few questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.
