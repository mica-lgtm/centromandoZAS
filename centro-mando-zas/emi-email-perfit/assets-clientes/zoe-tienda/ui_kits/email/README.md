# UI Kit — Email marketing

Newsletter mobile-first de Zoe Tienda: banner limpio, jerarquía clara, CTAs visibles.

**Abrir:** `index.html` — email renderizado dentro de un marco de teléfono (390px).

## Bloques (`EmailBlocks.jsx`)
- `EmailHeader` — barra de logo + link a tienda.
- `EmailHero` — banner verde con promo + CTA.
- `EmailProducts` — grilla 2-up de productos (placeholder + título/autor/precio).
- `EmailPromo` — bloque suave verde (club de lectura).
- `EmailFooter` — ink, logo blanco, links y baja.

## Notas
- **Mobile-first**, ancho objetivo ~390–600px. Textos breves, contraste alto para modo claro/oscuro.
- Portadas = placeholders; reemplazar con imágenes reales sin deformar.
- Sin códigos de barras. No inventar precios/promos.
