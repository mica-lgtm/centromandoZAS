# marcas/ · Memoria por marca

Cada marca debe tener su propio archivo para guardar tono, campañas, promociones confirmadas, links, referencias visuales, aprendizajes y errores a evitar.

Emi debe leer primero el archivo de la marca antes de crear una campaña.

No sobrecargar `CLAUDE.md` con datos de marca. La memoria específica vive acá.

## Formato recomendado por marca

```md
# Marca

## Estado de contexto

## Tono de voz

## Público objetivo

## Productos / categorías importantes

## Promociones confirmadas

## Links importantes

## Referencias de emails anteriores

## Reglas de copy

## Reglas visuales

## Campañas realizadas

## Aprendizajes

## Datos a validar
```
