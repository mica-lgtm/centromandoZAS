# Skill · Revisar entregabilidad básica

## Objetivo

Reducir riesgos básicos de spam, baja apertura o mala experiencia de lectura.

## Checklist

- [ ] Asunto claro y no engañoso.
- [ ] No hay exceso de mayúsculas.
- [ ] No hay exceso de signos de exclamación.
- [ ] No hay exceso de emojis.
- [ ] Preheader complementa el asunto.
- [ ] El contenido cumple lo que promete el asunto.
- [ ] No hay claims exagerados.
- [ ] CTA visible.
- [ ] Equilibrio razonable entre texto e imagen.
- [ ] Links principales funcionan o están listados para validar.
- [ ] Footer y desuscripción presentes.

## Reglas

La revisión de entregabilidad de Emi es básica. Si hace falta análisis profundo, derivar a Dani o a Rita según corresponda.
