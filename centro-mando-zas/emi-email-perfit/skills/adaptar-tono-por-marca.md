# Skill · Adaptar tono por marca

## Objetivo

Ajustar copy, ritmo, emojis, intensidad comercial y estilo visual según cada marca.

## Procedimiento

1. Leer archivo de marca en `marcas/`.
2. Revisar manual de marca o referencias si están disponibles.
3. Identificar:
   - Tono.
   - Público.
   - Nivel de cercanía.
   - Nivel de venta directa permitido.
   - Uso de emojis.
   - Palabras frecuentes.
   - Palabras a evitar.
4. Adaptar asunto, preheader, hero, cuerpo y CTA.
5. Si no hay contexto suficiente, usar voseo argentino profesional y marcar que falta validar tono.

## Reglas

- No usar el mismo tono para todas las marcas.
- No mezclar tonos entre clientes.
- No usar emojis si la marca no los usa.
- No exagerar cercanía en marcas más técnicas o premium.
- No hacer copy frío en marcas cálidas, infantiles o emocionales.
