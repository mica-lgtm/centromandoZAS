# Skill · Crear prompt de imagen para email

## Objetivo

Crear un prompt claro para generar imágenes de email cuando no hay URL pública o recurso visual disponible.

## Cuándo usar

- No hay banner.
- No hay imagen de producto.
- La campaña necesita una imagen hero.
- Mica pide generar visual.

## Procedimiento

1. Identificar marca.
2. Leer tono y estética de marca.
3. Identificar tipo de campaña.
4. Definir formato recomendado: banner horizontal, hero cuadrado, producto en contexto, composición editorial, etc.
5. Crear prompt claro y usable.
6. Aclarar estilo, colores, composición, texto o ausencia de texto.

## Formato de salida

```md
## Prompt de imagen sugerido

Crear una imagen [formato] para [marca], con estilo [estética], mostrando [elementos], transmitiendo [sensación], usando colores [paleta], composición [detalle]. Evitar [cosas a evitar]. Sin texto / con texto: [indicar].

## Uso recomendado

Hero / banner / producto / bloque editorial.

## Medida sugerida

Ej: 1200x628, 1080x1080, 600x400.
```

## Reglas

Si la imagen incluye texto, debe ser breve. Para email, muchas veces conviene que el texto principal esté en HTML y no dentro de la imagen.
