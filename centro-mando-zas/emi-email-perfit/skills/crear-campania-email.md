# Skill · Crear campaña de email

## Objetivo

Crear una campaña de email marketing completa para Perfit, con estrategia, copy, estructura visual y, si se solicita, HTML final.

## Entrada mínima

- Marca.
- Objetivo.
- Tipo de campaña.
- Producto, categoría o tema.
- Promoción si existe.
- Segmento si está definido.
- Links.
- Referencias o manual de marca si existen.

## Procedimiento

1. Identificar la marca.
2. Leer `marcas/[marca].md`.
3. Leer contexto del proyecto principal si está disponible.
4. Clasificar tipo de campaña.
5. Detectar si faltan datos críticos.
6. Si faltan datos críticos, preguntar.
7. Si no faltan, definir estrategia.
8. Proponer segmento recomendado.
9. Crear asunto, preheader y asunto de reenvío.
10. Crear estructura del email.
11. Redactar copy completo.
12. Definir idea visual y módulos.
13. Listar links y datos a validar.
14. Si se pidió HTML, ejecutar skill `crear-html-perfit.md`.
15. Preparar brief para Rita.

## Formato de salida

Usar `templates/estructura-entrega-campania.md`.

## Regla importante

Si Mica pide varias campañas, entregar primero una campaña completa para validar diseño y estructura. No avanzar con el resto hasta recibir aprobación.
