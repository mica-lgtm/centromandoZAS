# Skill · Preparar brief para Rita

## Objetivo

Preparar una entrega ordenada para que Rita revise la campaña sin tener que reconstruir contexto.

## Cuándo usar

Antes de considerar una campaña lista para entregar o implementar.

## Formato

```md
# Brief para Rita

## Marca

## Objetivo de campaña

## Tipo de campaña

## Segmento

## Asunto

## Preheader

## Asunto de reenvío

## Copy final

## Links usados

## Promociones / beneficios mencionados

## Imágenes usadas

## Datos que necesitan validación

## HTML generado

## Pedido específico para Rita

Revisar tono, ortografía, claridad, promociones, links, CTA, consistencia de marca, mobile, modo oscuro y compatibilidad básica del HTML para Perfit.
```

## Reglas

No ocultar supuestos. Todo dato no validado debe llegar marcado a Rita.
