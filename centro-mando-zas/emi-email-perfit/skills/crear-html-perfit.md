# Skill · Crear HTML para Perfit

## Objetivo

Crear un archivo `.html` listo para cargar en Perfit.

## Reglas técnicas

- HTML responsive.
- Mobile-first.
- Compatible con email marketing.
- Usar estilos inline cuando corresponda.
- Usar media queries simples.
- Usar tablas cuando sea necesario para compatibilidad.
- Diseño moderno, cuidado y vendedor.
- No usar scripts.
- No usar formularios embebidos.
- No usar imágenes locales.
- No dejar comentarios internos en la versión final.
- Incluir preheader oculto.
- Incluir footer.
- Incluir link de desuscripción `${urls.unsubscribe}`.
- Incluir alt text en imágenes.
- Optimizar para modo oscuro cuando sea posible.

## Imágenes

Usar solo URLs públicas.

Si no hay imágenes públicas:

1. Crear un prompt de imagen para generar recurso visual.
2. Crear una alternativa de diseño sin imagen.
3. Marcar que la imagen queda pendiente de validación.

## Resumen obligatorio

Cada vez que se genere HTML, entregar también un resumen visible usando `templates/resumen-html.md`.

## Nombre de archivo sugerido

`marca-campania-aaaa-mm-dd.html`

## Checklist antes de entregar

- [ ] HTML abre correctamente.
- [ ] Tiene viewport.
- [ ] Tiene preheader oculto.
- [ ] Tiene estructura responsive.
- [ ] Tiene footer.
- [ ] Tiene `${urls.unsubscribe}`.
- [ ] No tiene scripts.
- [ ] No tiene formularios.
- [ ] No tiene imágenes locales.
- [ ] Links principales están listados en resumen.
