🚀 Reporte de Avance

Centro de Mando ZAS — Sistema de Campañas + Retroalimentación Automática

🎯 El Desafío

Automatizar creación de campañas de email para múltiples clientes + analizar performance en tiempo real para mejorar cada nueva campaña.

Se necesitaba un sistema que permitiera:

  • Crear campañas por API sin usar interfaz web
  • Analizar performance automáticamente cada 48 horas
  • Generar propuestas de campañas basadas en patrones reales
  • Escalar a múltiples clientes sin duplicar esfuerzo

📊 Parte 1: Vitalis Navitas (Klaviyo)

🔍 Análisis Automático de Performance

Problema: No había feedback automático de performance para aplicar en próximas campañas.

Solución: Sistema automático que cada 48 horas:

  • Trae datos de campañas enviadas en últimas 48hs desde Klaviyo
  • Analiza: open rate, CTR, bounce, unsubscribe
  • Detecta top 3 asuntos ganadores y patrones de éxito
  • Genera reportes en retroalimentacion-vitalis/
  • Identifica reglas para próximas campañas
Artefactos creados:
• Skill: analizar-performance-klaviyo.md
• Rutina cloud: cada 48hs a las 9 AM Argentina
• Histórico: 100 campañas analizadas

🎨 Parte 2: Simona Shop + Todas las Cuentas Perfit

🔧 2A — Sistema de Creación por API

Problema: Crear campañas solo por API, sin interfaz web.

Solución:

  • Skill completo: crear-campana-perfit-api.md
  • Script individual: create_campaign.py
  • Script batch: batch_create_campaigns.py
  • Crea campañas en borrador, validadas, listas para enviar
Caso real: 6 campañas Simona creadas en Perfit (IDs 1309-1314) en <1 minuto, con HTML, sender, recipients y validación completa.

🧠 2B — Sistema de Retroalimentación + Propuestas

Problema: Automatizar análisis Y generar propuestas de nuevas campañas basadas en patrones reales.

Solución: Cada 48 horas:

  • Analiza performance de campañas pasadas
  • Detecta patrones ganadores/perdedores
  • Genera automáticamente 3 propuestas lisas para revisar
  • Propuestas contienen: estrategia, asunto, preheader, segmentación, CTA
Artefactos:
• Skill: analizar-performance-perfit.md
• Script: analizar_performance_perfit.py
• Archivos generados: análisis + 3 propuestas JSON

✅ 2C — Flujo de Aprobación y Envío

El workflow completo:

1. Análisis automático (48hs)

Sistema analiza campañas pasadas y genera 3 propuestas

2. Tú editas y apruebas

Revisas propuestas, editas asuntos/preheaders, cambias estado a "aprobada"

3. Crear en Perfit (borrador)

crear_campanas_aprobadas.py crea campañas en Perfit automáticamente

4. Emi agrega HTML

Agente genera diseño responsive personalizado por marca

5. Tú validas en Perfit

Revisas preview, links, diseño mobile, marca

6. Envía campañas

enviar_campanas_aprobadas.py lanza automáticamente

7. Monitorea performance

Próximo ciclo: 48hs después, análisis automático nuevamente

Scripts:
• crear_campanas_aprobadas.py → Crea desde propuestas aprobadas
• enviar_campanas_aprobadas.py → Lanza campañas validadas
